\# Jenkins Setup Instructions



\## 1. Verify Java



```cmd

java -version

```



\## 2. Check Jenkins Service



Open Windows Services by running:



```cmd

services.msc

```



Find the Jenkins service and check whether it is running.



\## 3. Access Jenkins



Open the browser and visit:



http://localhost:8080



\## 4. Complete Initial Configuration



\- Unlock Jenkins if prompted.

\- Install suggested plugins.

\- Create an administrator account.

\- Open the Jenkins dashboard.



\## 5. Explore Jenkins



Explore the dashboard, manage plugins, review system information, and examine the options for creating jobs and pipelines.



\## Security Note



Do not upload administrator passwords, initial unlock passwords, API tokens, or other credentials to GitHub.
