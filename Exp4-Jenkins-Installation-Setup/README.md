\# EXPERIMENT NO: 4



\## Jenkins Installation and Setup



\### Aim

To install and configure Jenkins and explore its environment for Continuous Integration and Continuous Deployment (CI/CD).



\### Description

Jenkins is an open-source automation server used to automate software building, testing, and deployment. It helps developers integrate code changes frequently and automate repetitive development tasks.



\### Requirements

\- Windows operating system

\- Jenkins installed on the laptop

\- Java Development Kit (JDK)

\- Web browser

\- Internet connection



\### Procedure

1\. Install Java and verify the installation.

2\. Download and install Jenkins.

3\. Start the Jenkins service using Windows Services.

4\. Open `http://localhost:8080` in a web browser.

5\. Complete the Jenkins setup wizard.

6\. Install the recommended plugins.

7\. Create the administrator account.

8\. Explore the Jenkins dashboard and available features.



\### Features Explored

\- Jenkins Dashboard

\- Build history

\- Plugin management

\- System configuration

\- Job and pipeline management



\### Result

Jenkins was installed and configured successfully. The Jenkins web interface was accessed locally, and its environment and basic features were explored.
